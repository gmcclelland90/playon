# Hostability

Before installing anything, classify the title:

| Class | Meaning | Agent action |
|-------|---------|--------------|
| **Dedicated shipped** | Official or well-known DS binary/image | Proceed with a skill or draft |
| **Listen / P2P only** | Someone’s client must host | Do **not** create a dedicated server; explain listen/hosting limits |
| **Publisher cloud only** | No self-host binaries | Refuse; suggest official multiplayer |
| **Third-party MP framework** | FiveM, RageMP, BeamMP, etc. | Treat as a separate product + licensing; do not pretend it is vanilla |
| **Emulated / private server** | Reverse-engineered online titles | Default refuse (ToS/legal); only continue if the host explicitly overrides |

## How to decide quickly

1. `skill_list` / future marketplace — if an official PlayOn skill exists, trust it.
2. Look for a **Dedicated Server** Steam tool, Docker image, or vendor headless download.
3. If multiplayer is only “Invite friends” / Steam lobby with no server files → listen/P2P.
4. If the only path is a paid official server browser with no binaries → publisher cloud.

## Voice / amenity servers

Mumble/TeamSpeak are optional LAN amenities, not game skills. Do not block a party on them.
