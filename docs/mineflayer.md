# Mineflayer bots on PlayOn Minecraft

PlayOn Minecraft (Java / Paper) servers accept the same join path as a normal client. [Mineflayer](https://github.com/PrismarineJS/mineflayer) bots can connect to that host:port.

Reference implementation: [gmcclelland90/grokbot-mineflayer](https://github.com/gmcclelland90/grokbot-mineflayer). Other Grok bots should fork that repo. Players still use the normal Minecraft client.

Public Paper instance used by that bot: `minecraft.playon.games:25566` (Paper 1.21.11, Small Minecraft / `games.minecraft-paper-small`). Curated `games.*` packages live in sibling [playon-games](https://github.com/gmcclelland90/playon-games), not this repo.
