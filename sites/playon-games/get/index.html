PlayOn

Get PlayOn

Install however you like. Docker is optional — native and SteamCMD work without it.

Home (recommended)

Linux party box or mini-PC — control plane + local node:

curl -fsSL https://playon.games/downloads/playon-home-latest.tar.gz | tar -xz
cd playon && sudo bash deploy/install.sh

Windows: extract the Home zip, elevated PowerShell:

.\deploy\windows\install.ps1

Optional Docker panel

Panel in Compose; keep a host-native node for SteamCMD:

docker compose -f deploy/docker-compose.yml up -d

Add a LAN node

From the panel (or after Home install), on a second machine:

sudo bash deploy/install-node.sh --api http://<home-ip>:8787 --token <PLAYON_NODE_TOKEN>

Cloud (Vultr)

In Settings → Cloud capacity → Connect Vultr (OAuth via connect.playon.games). Place individual servers on a nearby VPS when the LAN is full.
