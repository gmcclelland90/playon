# PlayOn

## Register
product

## Platform
web

## Users
LAN hosts and co-organisers managing dedicated game servers; players joining via a phone-friendly panel.

## Purpose
Self-hosted AI control plane that turns “let’s play X” into a running server with join info, using skills, scoped tools, and pluggable LLMs (cloud API key or Ollama).

## Positioning
Conversation-first game-server ops for LAN nights — not a commercial multi-tenant host, not a generic cloud console.

## Brand personality
Confident booth energy: sharp, playful, trustworthy. Rose stage-light on matte black gear — fun without toyish, dense without SaaS-cream.

## Anti-references
Purple-on-white AI dashboards, cream/terracotta editorial kits, neon cyberpunk glassmorphism, generic “admin admin” Bootstrap panels, hero-metric SaaS cards.

## Accessibility
WCAG AA minimum; keyboard-complete core flows (setup, login, chat, settings); visible focus; motion respects `prefers-reduced-motion`.
