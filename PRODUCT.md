# Product

## Register

product

## Platform

web

## Users

Primary: LAN hosts and co-organisers managing dedicated game servers on a local network. Secondary: players joining via the phone-friendly `/play` panel. Context is a same-night party or session — get a game up, share join info, keep fiddling low.

## Product Purpose

Self-hosted AI control plane that turns “let’s play X” into a running server with join info, using skills, scoped tools, and pluggable LLMs (cloud API key or Ollama). Success is same-night: ask for a game → server is up → players have join info on `/play` with minimal fiddling.

## Positioning

Conversation-first game-server ops for LAN nights — not a commercial multi-tenant host, not a generic cloud console.

## Brand Personality

Sharp, playful, trustworthy. Confident booth energy: fun without toyish, dense without SaaS-cream. Rose stage-light on matte black gear.

## Anti-references

Purple-on-white AI dashboards, cream/terracotta editorial kits, neon cyberpunk glassmorphism, generic “admin admin” Bootstrap panels, hero-metric SaaS cards.

## Design Principles

1. **Conversation is the control surface** — intent → running server happens in chat/map first; panels support that, they don’t replace it.
2. **Same-night payoff** — optimize for “let’s play X” tonight with join info on `/play`, not enterprise ceremony.
3. **Two audiences, two tempos** — dense host booth for ops; calm, scan-first player panel for phones.
4. **Playful without toyish** — sharp / playful / trustworthy; never carnival UI or SaaS-cream.
5. **Self-hosted LAN ops** — reinforce local control plane, not multi-tenant cloud console vibes.

## Accessibility & Inclusion

WCAG AA minimum; keyboard-complete core flows (setup, login, chat, settings); visible focus; motion respects `prefers-reduced-motion`.
